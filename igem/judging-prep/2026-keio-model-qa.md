# iGEM Keio Japan 2026「One Direction」 Modelページ 想定質問集

- 出典: https://2026.igem.wiki/keio-japan/model/
- プロジェクト概要: 細胞の向きを制御し、方向性のある細胞間接着を実現する「One Direction」。
  3つの技術課題に対応する3つのモデルで構成。
  1. **Model 1（拡散シミュレーション）**: DivIVA/PopZによる極局在の非対称化機構の選定（steric occlusion vs
     localized degradation）とウェットラブへのフィードバック。ウェット画像によるキャリブレーション・検証済み。
  2. **Model 2（分子動力学シミュレーション）**: コイルドコイル（CoilE/CoilR）の結合安定性評価とリンカー選定
     （GROMACS + umbrella sampling + PMF）。
  3. **Model 3（細胞凝集シミュレーション）**: 接着因子の局在状態（極局在割合 f_pole・先端集中度 w）が
     鎖状構造 vs 塊状構造のどちらを作るかを決める幾何モデル＋時間発展シミュレーション。

自チームの審査対応力強化のためのベンチマーク資料（McGill CoHeraのQ&A集と対で使用）。

---

## 1. 全体設計・モデル間統合に関する質問

1. Model 1（PopZ/DivIVA局在）、Model 2（コイルドコイル/リンカー）、Model 3（細胞凝集）は独立に構築されているように見えるが、各モデルの出力は他のモデルの入力パラメータとして数値的に連携しているか？例えば、Model 2で選んだ(GGGGS)3リンカーの物理特性は、Model 3で使われているCostan et al.由来の接着因子パラメータ（F_b = 16.1 pN等）に反映されているか？
2. Model 3で使用した結合力・接着因子密度などの物理定数はCostan et al.の別の合成接着因子系の実測値を流用している。本プロジェクトの実際のコイルドコイル系とこれらの値がどの程度一致すると考えているか？
3. なぜ3つの独立したモデルに分けたのか？スケールをまたいだ単一の統合モデル（分子→細胞内局在→細胞集団）を構築しなかった理由は？
4. 3つのモデルのうち、ウェットラブでの実験的検証（キャリブレーション）が行われているのはModel 1のみである。Model 2・Model 3の予測はどの程度ウェットラブの結果と一致しているか、あるいは今後どう検証する計画か？

## 2. Model 1（拡散シミュレーション：DivIVA/PopZ）に関する質問

5. 効果的な機構として採用したsteric occlusionの鍵となる量θ（PopZによるDivIVA結合阻害の強さ）は未測定のままモデルの結論（3倍の極性比にはθ≈0.75が必要）が導かれている。この未測定パラメータに依存する結論の確度をどう評価しているか？
6. 成長指数pの推定値（p = 0.07 ± 0.061、IPTG条件によってはα = 1.91、つまりp ≈ 0.5）が条件によって大きく変動している。この不確実性はモデルの結論（pは局在の強さに影響しない等）にどの程度影響するか？
7. モデルとウェットデータの一致度「72%」は、ベースラインの定義（膜結合率70%の仮定）やライン幅・PSFの選択によって56〜125%まで変動することが自ら示されている。この単一の「72%」という数字を審査員にどう提示し、過大評価を避けるか？
8. PopZ共発現実験の結果（R = 0.90、PopZがある極にDivIVAがより多く残る）はモデルの予測（Rは1から単調に増加するはず）と逆方向だった。この不一致を「DivIVAのN末端にナンセンス変異があったため」と事後的に説明しているが、再実験で本当にモデルの予測方向に結果が変わることを確認したか？まだ確認できていない段階でこの説明をどこまで主張してよいか？
9. f_nm（クラスター崩壊後に分子が膜に戻るか細胞質に戻るかの分岐比）は「原理的に決定不可能」として0と1の両端をスイープし、結果がその間に収まることだけを確認している。この扱いは科学的に十分と言えるか、それとも別の実験デザインで決定できる可能性はないか？
10. 大腸菌にはDivIVAが天然には存在しないため、速度定数の大部分をB. subtilisの文献値に依存している。この種間移植可能性そのものが仮定であることについて、どの程度のリスクと見ているか？
11. クラスターの曲率認識エネルギー計算に用いた持続長100 nmはDivIVA固有の実測値ではない。model-2 README（日本語版）では「1桁の不確かさで必要クラスター分子数が34倍動く」と記載されているが、英語版wikiにはこの感度分析の記載が見当たらない。この重要な不確実性は最終的な結論にどう影響するか？
12. 手動で選別した解析対象細胞（選別率23〜48%、明るさのAUC 0.60〜0.76）という選択バイアスについて、「局在の強い細胞が選ばれた証拠はない」としているが、他の交絡（細胞の健康状態、発現タイミング等）によるバイアスの可能性は排除できているか？
13. 隔壁（septum）を含まないモデルで、キャリブレーション基準の「66%が極・隔壁に存在」という値から隔壁の寄与を5〜15%と事後的に推定し補正している。この補正自体の不確かさ（文献で確認されていない仮定）がθの設計目標に与える影響は本当に無視できるか？

## 3. Model 2（分子動力学：コイルドコイル安定性・リンカー選定）に関する質問

14. コイルドコイル単体の安定性評価は100 nsのシミュレーションを1回のみ実施している。この結果の統計的信頼性（seed依存性やばらつき）をどう保証しているか？
15. PMF計算に用いたumbrella samplingは各ウィンドウ5 nsと比較的短い。WHAM解析の収束性（ヒストグラムの重なり、誤差推定）はどのように確認したか？
16. リンカー比較（EAAAK, GGGGS, GSSGSSGS, GS）は各リンカーにつき10 nsのシミュレーションを1回のみ実施し、水素結合・塩橋・疎水性相互作用の「数」のみで安定性を判断している。この評価指標だけで実際の結合の強さ・寿命を十分に反映できるか？より直接的な指標（結合自由エネルギー、解離時間等）を計算しなかった理由は？
17. コイルドコイル単体の安定性評価（AMBER99SB-ILDN + TIP3P）と膜組み込みモデルの構築（CHARMM-GUIベース、通常CHARMM36系を使用）で力場が異なる可能性がある。この力場の違いが結果の一貫性にどう影響するか？
18. 剛直リンカー(EAAAK)6で解離が2回観測された一方、柔軟リンカー(GGGGS)3は安定だったと結論づけているが、各リンカーにつき1回のシミュレーションのみでの判断である。もし(EAAAK)6を複数回試行したら、常に解離するのか、確率的な現象なのか？
19. 実際の生体内環境（ペリプラズム内の分子クラウディング、他の膜タンパク質との相互作用）を、10 nsという短時間・単純化された二重膜モデルでどこまで再現できていると考えているか？
20. Pulling simulationの方向を変更した（Cycle 1のDBTL）ことで望ましい初期構造が得られたとあるが、この手法変更がPMFの絶対値や形状にバイアスを与えていないことをどう確認したか？

## 4. Model 3（細胞凝集シミュレーション）に関する質問

21. 先端集中度w（ガウス分布の幅）は文献値がなく、モデルの仮定（ガウス型の濃度分布）自体も実測に基づいていない。この最も不確かなパラメータに、鎖形成に必要な極局在割合f_pole（68%や44%といった具体的な目標値）という設計指針の結論全体が強く依存していることについて、どう正当化するか？
22. 接着結合の解離速度k_offを「ほぼゼロ（解離しない）」と仮定しているが、これは文献上「区別できない」という記述に基づく。実際に長時間（24時間の静置培養）という時間スケールで本当に解離が無視できるという保証はあるか？
23. 局在を達成しても24個中わずか約3個の細胞のみが「純粋な鎖」を形成するという結果は、プロジェクトの核心的な主張（方向性のある細胞接着で鎖を作る）にとって深刻な制約ではないか？この「純度の低さ」は応用上どの程度許容されるか？
24. シミュレーションは2次元平面上で行われているが、実際の細胞凝集は3次元空間（培養液中）で起こる。2次元近似が密度・拡散・衝突頻度に与える影響をどう評価したか？
25. 振動撹拌・遊泳・沈降に関するパラメータ推定（せん断速度、拡散係数等）は「モデルによる推定値であり文献値そのものではない」との注記が複数ある。これらの大まかな推定に基づく結論（撹拌では結合が壊れない等）の確度は？
26. 凝集速度（モノマーが半分に減る時間）の傾向が、シミュレーションボックスのサイズに依存して逆転するため「結論は出さない」としている。この系自体の数値的な安定性・有限サイズ効果についてどう理解しているか？
27. このモデルの予測（f_pole, wの目標値）は、実際のウェットラブの凝集アッセイ結果とまだ比較されていない。今後どのように実験的に検証する計画か（例えば蛍光顕微鏡でwを実測する、等）？

## 5. 限界・今後の展望に関する質問

28. Model 1・2・3それぞれが挙げている限界（θ未測定、単一MD run、wのガウス仮定等）のうち、プロジェクト全体の工学的成功（One Directionの実現可能性）にとって最もクリティカルなのはどれか？
29. 「JUDGING」という専用ページがwiki内に存在するが、Modelページで提示した主張のうち、審査基準（Model, Engineering Success等）に対してどの主張が最も強いエビデンスを持つと自己評価しているか？
30. 今後、Model 1のPopZ再実験、Model 2の追加リンカー検証、Model 3のw実測が計画されているが、時間的制約の中でどれを最優先するか？

## 特に突かれやすい点

- **Model 1 / #8**: PopZ共発現実験がモデルの予測と逆方向の結果を示し、その説明（ナンセンス変異）がまだ再実験で確認されていない点。審査員は「結果が都合悪いときに後付けの説明をしていないか」を疑う。
- **Model 1 / #6-7**: pの推定が不安定（条件により0.07〜0.5相当まで変動）であり、かつモデル全体の「一致度72%」も指標の定義で56〜125%まで動く。数字の一人歩きに注意。
- **Model 2 / #16, #18**: 各リンカーにつき1回のシミュレーションのみで結論を出している点（再現性の弱さ）。
- **Model 3 / #21, #23**: 核心パラメータw（先端集中度）が未測定のまま設計目標値を導出している点、および局在してもなお大半の細胞が「純粋な鎖」にならない点。
